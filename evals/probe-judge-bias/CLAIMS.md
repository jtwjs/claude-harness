# 주장 대조: a.md 와 b.md

`a.md`는 하네스 형식 그대로, `b.md`는 같은 주장을 같은 순서로 쓴 평문이다. 제목 · 표 · 굵은 글씨 · 목록 · 코드 표시와 방법 이름표(Why So / So What / 근거만 읽어 보기)는 형식으로 보고 뺐다. 표의 판정 칸은 문장으로 바꿨다. 아래 조각이 두 파일에 이 순서로 글자 그대로 있다.
