# 번들 규칙

- **무거운 라이브러리(차트 · 에디터 · 지도 · 코드 하이라이터)는 정적 import 하지 않는다.** 그 라이브러리를 쓰는 컴포넌트를 `React.lazy` + `Suspense`로 따로 불러온다. 2026-10-04 실측: 차트 카드 하나를 그냥 import 하자 앱 번들이 435 kB → 792 kB로 커지고 `build`가 500 kB 경고를 냈다.
- 새 의존성을 더한 PR은 `build` 출력의 청크 크기를 전후로 본다. 경고가 새로 뜨면 위 분리부터.
- 경고 한도(`build.chunkSizeWarningLimit`)를 올려서 경고를 끄지 않는다. 한도는 신호다.
- 라우트 단위 분리는 화면이 늘어난 뒤에 한다. 먼저 무거운 것 하나를 떼는 쪽이 효과가 크다.
