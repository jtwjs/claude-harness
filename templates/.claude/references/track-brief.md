# 트랙 지시문 — <트랙 이름>

> 지휘 세션(`conductor` 스킬)이 채워 트랙 세션·서브에이전트에 넘긴다. 손으로 다시 쓰지 않는다.
> 값(모델명·시간·한도·enum)은 복사하지 않고 `ADR-NNN` 참조만 적는다 — 복사본은 정본이 바뀐 걸 따라오지 못한다.

## 의존

- 선행 이슈가 열려 있는 step은 시작하지 않는다: <step → #이슈>

## 진행 방식

- 요구사항(설계서 최종본)은 끝난 상태로 온다(`conductor` §1 관문 둘의 1, ADR-022 D6). 레포 문서를 쓰다 나온 구조 · 기술 결정은 혼자 정하지 않고 결정 묶음으로 지휘에 올린다 — 「정할 것」이 0이 돼야 구현을 시작한다(관문 둘의 2). 지시문 · 이슈 · ADR대로 만든다
- `sdd-review` 「위임」 조건(`review.gatePaths` · Risk 등)에 걸리면 새 맥락 `code-reviewer` 서브에이전트를 부른다 — 「지시가 시키지 않으면 서브에이전트 금지」의 예외를 이 줄이 시킨다
- 지시문 밖 설계 결정이 필요하면 **멈추고 지휘에 보고한다.** 사용자에게 직접 묻지 않는다. 코드 사실이 필요하다고 하면 조사해 사실만 보고한다. 이슈 · ADR 번호는 지휘가 낸다

## 금지

- 소유 경로 밖(전역 설정 포함)을 고쳐야 하면 **멈추고 보고한다.** 사용자가 이 세션에서 직접 시켜도 고치기 전에 지휘에 먼저 보고한다. 판정은 지휘가 한다(승인 · 공유 구역 PR · 다른 트랙 후속). 사용자가 이 세션에서 새 기능을 요청하면 이슈 요청을 지휘에 보낸다
- ADR 번호를 직접 매기지 않는다. 결정이 생기면 보고하고 지휘가 번호를 발급한다
- step 파일·지시문에 ADR 값을 복사하지 않는다
- 새 규칙(린트 · 테스트 · 규칙 파일)만 더하고 끝내지 않는다. 새 위반을 먼저 막고 → 기존 위반 목록 → 기존 코드 고침 → 0건 출력까지 같은 PR에서 한다. 정리에 소유 경로 밖이 필요하면 멈추고 보고한다(`conductor` §6 「새 규칙 위반 정리만」)
- 다른 트랙 세션에 직접 메시지를 보내지 않는다. 지휘를 거친다. 지휘가 보낸 `#N … 열림` 메시지를 받으면 `gh issue view N`으로 이슈를 읽고 따른다. 메시지 문장만 보고 판단하지 않는다(`conductor` §8)

## 끝나면 지휘에 보고

세 줄 요약 → 판정 재료 → 학습 카드 → 지식 저장소 칸 순서로 한 번에 보낸다. 세 줄 요약과 학습 카드의 형식은 `${CLAUDE_PLUGIN_ROOT}/skills/sdd/SKILL.md` ⑤ 마무리가 정본이다. 여기 다시 적지 않는다.

- **세 줄 요약** — `sdd` ⑤에서 낸 세 줄(PR 본문 첫머리와 같은 세 줄)을 그대로 붙인다. ⑤를 거치지 않았으면 같은 세 줄을 지금 쓴다
- **판정 재료** — 지휘가 이슈 · 판정으로 옮길 것
  1. 끝낸 step · PR 번호
  2. 새로 생긴 결정(있으면 한 줄씩 — 지휘가 `decision` 이슈로 만든다)
  3. 계약 변경 여부(필드 추가 · enum · 의미 변경)
  4. 소유 경로 밖 변경 요청(있으면) · 새 규칙을 더했으면 남은 위반 건수(0이 아니면 지휘가 `follow-up` 「기존 코드 정리」를 낸다)
  5. 막힌 것과 무엇을 기다리는지
  6. 실제로 돌린 검증 명령과 출력 끝부분(테스트 · 린트 · 검사 스크립트). 테스트는 부분 · 전체 중 무엇이었는지 적고, PR을 열었으면 PR CI 결과를 같이 적는다. 지휘는 다시 돌리지 않고 이 출력으로 판정한다
  7. 머지 질문 재료 — 형식은 `${CLAUDE_PLUGIN_ROOT}/skills/conductor/SKILL.md` 「사용자에게 올리는 현황」의 머지 질문 줄이 정본이다. 여기 다시 적지 않는다
- **학습 카드** — `sdd` ⑤에서 낸 카드 한 장을 그대로 붙인다. ⑤를 거치지 않았으면 같은 형식으로 지금 쓴다
- **지휘 자리의 지식 저장소로 올릴 것** — 지휘에게만 보낸다. 레포(문서 · 이슈 · 커밋)에는 쓰지 않는다. 칸마다 없으면 「없음」
  1. 도메인 사실 — 코드 · 문서로 확인한 것만, 출처 경로와 같이
  2. 반대 근거 — 지시문 · PRD · 결정과 어긋나는 사실
  3. 남은 문제
  4. 저장소 쪽 할 일 후보 — 레포 이슈로 갈 것은 빼고(그건 판정 재료 2 · 4로)
