# 0.44.0

- 릴리스 필요 알림: 지휘 현황 훅(`hooks/conductor-context.sh`)이 하네스 원본 레포 줄(레포 `plugin.json` `name` = 설치본 `name`)에 「릴리스 안 된 머지 n건 #A · #B … (설치본 X)」를 붙인다. 기준점은 `origin/main` first-parent에서 `version`이 설치본 버전이 된 가장 최근 커밋이고, `gh api …/compare` 1회(5초 제한)로 그 뒤 머지를 센다(문서만 바꾼 머지 · 버전 올림 머지도 센다). PR 번호는 오래된 것부터 5개, 넘으면 「외 m건」. 설치본 · 기준점 · 원격 · 레포 `plugin.json` 중 하나를 못 읽으면 0건 대신 「릴리스 확인 실패」(대개 사유 포함)를 그 줄에만 붙인다(#94 · #80)
- 템플릿 뒤처짐: 대상 레포 `.claude/harness.json` `harness.version`이 설치본 `version`과 다르면 그 줄에 「템플릿 X → 설치본 Y」를 붙인다. 하네스 설정이 없거나 값이 비거나 깨졌으면 조용히 건너뛴다(레포 세션 알림과 같은 규칙)(#94 · #80)

- 주의: 지휘 세션 시작이 원격 조회 1회만큼 느려진다(가운데값 2.23 → 2.91초, 마감 25초 안). 버전 올림 PR 머지 뒤 릴리스 전에는 하네스 원본 줄의 템플릿 꼬리가 거꾸로(템플릿 > 설치본) 보일 수 있다(#94)
