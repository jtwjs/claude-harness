# 0.17.1

- 운영 DB 판별을 위치 참조로(0.17.1, 2026-10-13): 0.17.0은 `harness.json`에 호스트 값을 적게 했는데, 운영 호스트 값은 레포 밖·문서로 옮기지 않는다는 규칙과 부딪혔다. 이제 `from`에 위치만 적고(`spring:<프로필>` · `env:<파일>:<키>`) `hooks/lib/prod_db.py`가 실행 때 디스크에서 읽는다. yml의 `${VAR}`는 레포 `.env*`에서 풀고, 같은 호스트를 가리키는 Spring 프로필은 자동으로 운영 취급, 명령에 그 값을 담은 변수 이름(`$<운영 DB 환경 변수>`)이 나와도 운영으로 본다. Node는 `switches`. 못 읽으면 `prod-db-check`(SessionStart)가 '꺼짐'을 알린다(값은 출력 안 함). 실측: 사내 레포 F `spring:prod` → 호스트 1·자동 운영 프로필 prod·stage, 사내 레포 E `env:.env:<운영 DB 환경 변수>` → 호스트 1, 사내 레포 B는 운영 주소가 배포 env로만 들어가 디스크에 없음(적용 대상 아님). 결정 주체: 사람(위치 참조 방식 · Spring·Node 둘 다), AI 추천 수용(세션 시작 알림·변수 이름 매칭)
