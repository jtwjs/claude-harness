# 0.43.0

- 구현 시작 관문(ADR-023): `sdd_runner.py gate <docs 폴더>`가 `ADR.md` 「결정할 것」 표의 주체 빈 행과 `PRD.md` 「남은 ⚠️」 항목(`→ 결정:` · `막지 않음:` · 「없음」 제외)을 세어, 열린 것이 있으면 목록과 함께 종료 2로 멈춘다. `start`도 브랜치 · exclude를 건드리기 전에 같은 검사를 돌아, 헤드리스 `run`은 claude를 부르지 않고 멈춘다. 두 문서가 없으면 막지 않는다. `sdd-plan` §0이 폴더를 정한 직후 `gate`를 부른다. 표시 없는 「남은 ⚠️」가 남은 기존 phase도 다시 `start`하면 이제 멈춘다(#85 · #83)
- 관문이 놓치던 꼴을 센다: 변이 선택자 없는 「남은 ⚠」, 라벨 줄에 붙여 쓴 내용(`- **남은 ⚠️**: X 미정`), 번호 목록 · `+` 불렛, 셀 안 `\|`. 문서가 없을 때는 해석한 폴더 경로를 같이 내서 경로 오타와 가른다. 아직 통과하는 꼴은 `docs/sdd-runner.md` 「장치로 못 막는 갈래」에 적었다(#90 · #86)
- 재판정 진입점(나눔 모드): 구현이 blocked인데 검증 세션이 「테스트가 틀렸다」고 판정하면, 테스트만 고쳐 커밋한 뒤 `rejudge <task> --step N`을 부른다. 고친 테스트가 구현 전(BASE)에서 실패하는지 보고 `red`를 옮겨 구현 차례로 넘기며, 구현 커밋은 지우지 않는다. 두 번째 막힘은 종료 2(사용자에게), 차례가 아니면 종료 3. 이전에는 사람이 `red` · BASE · `wip` 커밋을 손으로 정리했다(#85 · #77)
- 재판정 보강: 경계를 러너가 blocked 판정 때 적은 `blocked_head`로 잡아, 구현 세션이 바꾼 테스트를 새 `red`로 받지 않는다(종료 1). 재시도 한도는 재판정 뒤 실패만 센다. RED 확인이 detached HEAD에서도 시작 지점으로 돌아온다(세션 하나 모드 `judge`의 같은 결함 포함). index.json step 선택 칸은 `rejudged`(#85)에 `blocked_head` · `rejudged[].attempts_before`가 더해진다(#90 · #86)
- 설계서 흐름(ADR-022): 사람이 읽고 고치는 설계 문서 한 장(설계서)을 `sdd` 설계 단계에 넣었다. 순서는 초안 → 사람 검수 · 수정 → 코드 사실 보강 → AI 재검토(번호 질문) → 한 번에 답 → 최종본이고, 레포 PRD · ARCHITECTURE · ADR은 최종본으로 쓴다. 혼자 도는 sdd면 `docs/{feature-date}/DESIGN-DOC.md`. 「PRD를 받았을 때」 갈래는 「설계서를 받았을 때」가 됐고, PRD에 비기능 · 제약 · 가정 칸, Readiness에 9~12행(설계서 ↔ PRD 대조 등)이 들었다(#84 · #82)
- ADR 틀: `design.md`의 ADR 틀에 「결정할 것」 표(`# · 정할 것 · 선택지 · 추천 · 주체`, 주체를 비우면 관문이 멈춘다)와 설계서 결정 번호 칸이 생겼다. 이 표 없이 옛 꼴로 쓴 ADR은 관문을 통과한다(#90 · #84)
- 지휘 관문 둘: `conductor`의 「디스패치 관문」이 「관문 둘」(디스패치 = 설계서 최종본 뒤 / 구현 시작 = 구조 · 기술 결정 「정할 것」 0)이 됐다. 트랙은 레포 문서를 쓰다 나온 결정을 파일:줄 근거와 함께 결정 묶음으로 지휘에 올리고, 사용자에게 직접 묻지 않는다. 사용자가 답하는 곳은 한 곳(Inbox)이고, 판정함 · `desk.py picks` 문구는 지휘 문서와 트랙 지시문 템플릿에서 뺐다(#84 · #82)
- 질문 규칙: 「한 번에 한 질문 + 3개까지」가 「라운드 기본」으로 바뀌고, 막는 장치 셋(이유 칸 · 새 갈래 찾기 · 물러서는 조건)이 들었다(`docs/principles/ask-questions.md`)(#84 · #82)
- 트랙 지시문 템플릿: 「설계서」 칸, `sdd-review` 「위임」 조건이면 새 맥락 `code-reviewer`를 부른다는 줄, 도메인 지식 링크 예시의 개인 경로를 `<개인 기록>/…`으로 일반화(#84 · #90)
- 문서: 설계 단계 보강 판정 ADR-022(#81 · #76) · 러너 구현 시작 관문 ADR-023 · PRD · ARCHITECTURE(#85)
