# 남이 읽는 글 (write-for-readers)

슬랙 · 노션 · PR 본문처럼 남이 읽는 글을 쓰거나 다듬을 때 따른다. 형식별 골격 · 상한 · 어미 · 기계 검사는 각 글 스킬에 있다.

번호는 다른 스킬이 인용한다. 지우거나 순서를 바꾸지 말고, 새 규칙은 마지막 번호 뒤에 붙인다.

## 쓸 때

1. **지어내지 않는다.** 사용자가 준 적 없는 근거 · 수치 · 사실은 쓰지 않는다. 없으면 `⚠️ 근거 필요`로 표시하고 묻는다.
2. **구조는 4단이 최대다.** ①결론 ②근거 · 현황(숫자 · 사실) ③판단 근거(내 해석임을 드러낸다) ④다음 액션. 짧은 글은 줄여 쓴다.
3. **형용사 대신 숫자로 쓴다.** `사용자 친화적` · `오래 방치됨` 대신 `34일째 업데이트 없음`.
4. **열린 질문은 제안값 + 확인 요청으로 바꾼다.** 제안값은 글에 이미 적은 논리에서만 끌어낸다.
5. **요청 문장은 음슴체로 끝내지 않는다.** `부탁드림`은 무례하게 읽힌다. 사실 서술의 음슴체는 괜찮고, 요청에 어떤 높임을 쓸지는 글 스킬이 정한다.
6. **12살 설명 · 비유 · 「쉽게 말하면」 풀이를 쓰지 않는다.** 쓰는 사람을 이해시키는 도구라, 받는 사람은 자기 업무의 좁은 맥락에서 쉬운 말을 다시 자기 용어로 옮기느라 더 어렵다. 상대가 쓰는 용어를 그대로 쓴다.

## 지울 때

7. **해석 · 요약 문장을 지운다**(`즉 ~입니다` · `~로 보입니다` · `정리하면`). 판별법: 앞 불릿 · 표 · 문단을 지웠을 때 이 문장도 성립하지 않으면 해석이다. 연결은 읽는 사람이 한다.
8. **em dash를 쓰지 않는다.** 사용자 초안에 있어도 지운다.

## AI 티

AI 티는 완벽하고 균일해서 난다.

9. **볼드 라벨 뒤에 마침표를 찍지 않는다**(`**현상.** / **영향.**`). 이런 라벨이 줄마다 붙어 있으면 순서는 두고 라벨을 걷어 문장으로 잇는다.
10. **모든 메시지 · 절의 블록 수를 맞추지 않는다.** 필요한 만큼만 쓴다.
11. **항목 수 · 하위 항목 수를 대칭으로 맞추지 않는다**(억지로 3개씩, 선택지마다 2+2). 있는 만큼만 쓴다.

## 밖으로 내기 전

12. **출처를 점검한다.** 숫자 · 인용마다 출처가 있는지(없으면 1번대로 `⚠️ 근거 필요`), 개인 노트 경로 · 내부 경로(로컬 파일 · 레포 경로 · wikilink)가 섞이지 않았는지 본다. 받는 사람은 그 경로를 열 수 없고, 한 번 나간 글은 거둘 수 없다.
