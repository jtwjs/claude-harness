# PRD — runner-test-time

> 원문: 사용자 지시(채팅, 지휘 경유), 이슈 없음 — 「러너 단위 테스트 시간을 줄인다. 단언 · 시나리오를 약하게 하지 않고 테스트 수를 줄이지 않는다. 낭비만 없앤다. ci.yml · test.sh는 안 건드린다. Before · After를 같은 방법으로 잰다.」 「에이전트 칸」 절만 검증 세션이 더했다.

## 원문

### 핵심 요구사항 한 줄 요약

러너 단위 테스트(`test_sdd_runner.py`)의 CI 시간을 줄인다 — 테스트 본문 · 단언 · 개수는 그대로. (← 사용자 지시)

### 현상

- CI에서 185개가 152.9s로 CI 시간의 약 절반이었다 (← 사용자 지시, 지휘가 전한 사실)

### 성공지표

- PR CI runner-unit 「Ran N tests in Xs」 3회 중앙값. 비포 150.607s(main 최근 CI 3회: 153.377s · 150.607s · 138.990s, 2026-11-28). 애프터는 이 PR CI 3회(재실행 포함) 중앙값 · 3회 모두 실패 0 (← 지휘 결정 2)
